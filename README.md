# TutorOS

Минимальный Telegram-сервис для домашних работ в учебных мини-группах.

На первом этапе в репозитории остаются только:

- Telegram-бот для преподавателя и учеников;
- хранение групп, учеников, заданий и результатов в Supabase;
- импорт методик из Google Sheets и отдельная выгрузка статистики;
- ежедневные напоминания о дедлайнах;
- SQL-схема и миграции базы.

Веб-интерфейс CRM, финансовые отчёты, маркетинговые панели и кабинеты сотрудников удалены.

## Переменные окружения

Скопируйте `.env.example` в `.env.local` для локальной разработки. Никогда не добавляйте `.env.local` в Git.

В рабочем окружении значения должны храниться в Vercel Environment Variables:

- `SUPABASE_URL` — адрес проекта Supabase;
- `SUPABASE_SECRET_KEY` — новый серверный secret-ключ Supabase;
- `TELEGRAM_BOT_TOKEN` — токен Telegram-бота;
- `TELEGRAM_WEBHOOK_SECRET` — секрет проверки запросов Telegram;
- `OWNER_TELEGRAM_ID` — Telegram ID преподавателя;
- `CRON_SECRET` — секрет запуска ежедневных напоминаний.
- `GOOGLE_SHEETS_WEBHOOK_URL` — адрес развёрнутого веб-приложения Apps Script;
- `GOOGLE_SHEETS_WEBHOOK_SECRET` — общий случайный секрет для обмена с таблицей.

Отдельный файл статистики подключается через Script Property
`TUTOROS_STATS_SPREADSHEET_ID`. Функция `syncTutorOSStatsFile` получает из
Supabase группы, учеников, ДЗ и результаты. `installTutorOSStatsTrigger`
включает обновление каждые 10 минут.

Код временно принимает и старую переменную `SUPABASE_SERVICE_ROLE_KEY`, чтобы
можно было заменить ключ без остановки бота. После успешного перехода старый
`service_role` следует отключить в Supabase.

После нового развёртывания откройте `/api/setup-webhook` на его домене и введите
`TELEGRAM_WEBHOOK_SECRET`. Страница привяжет Telegram-бота к этому домену, не
передавая токен бота в браузер.

## Как устроен первый рабочий контур

1. Базовая и продвинутая методики редактируются только в Google Sheets.
2. Команда `TutorOS → Синхронизировать методики` передаёт их в Supabase.
3. В Telegram преподаватель создаёт сколько угодно живых групп на основе одной
   методики, добавляет учеников и создаёт ДЗ к конкретному уроку.
4. Ученик сдаёт ответы или файлы в Telegram. Автопроверка и ручная проверка
   сохраняются в Supabase.
5. Статистика будет выгружаться из Supabase в отдельный, автоматически
   обновляемый файл Google Sheets. До его подключения старый технический журнал
   `_TutorOS` остаётся доступным только для совместимости.

Перед первым запуском этой версии выполните миграцию
[`supabase/migrate_course_templates.sql`](supabase/migrate_course_templates.sql).

Инструкция по подключению таблицы находится в
[`google-apps-script/README.md`](google-apps-script/README.md). Формат обмена
описан в [`docs/sync-contract.md`](docs/sync-contract.md).
