# TutorOS

Минимальный Telegram-сервис для домашних работ в учебных мини-группах.

На первом этапе в репозитории остаются только:

- Telegram-бот для преподавателя и учеников;
- хранение групп, учеников, заданий и результатов в Supabase;
- ежедневные напоминания о дедлайнах;
- SQL-схема и миграции базы.

Веб-интерфейс CRM, финансовые отчёты, маркетинговые панели и кабинеты сотрудников удалены.

## Переменные окружения

Скопируйте `.env.example` в `.env.local` для локальной разработки. Никогда не добавляйте `.env.local` в Git.

В рабочем окружении значения должны храниться в Vercel Environment Variables:

- `SUPABASE_URL` — адрес проекта Supabase;
- `SUPABASE_SECRET_KEY` — новый серверный secret-ключ Supabase;
- `TELEGRAM_BOT_TOKEN` — токен Telegram-бота;
- `TELEGRAM_WEBHOOK_SECRET` — секрет проверки запросов Telegram;
- `OWNER_TELEGRAM_ID` — Telegram ID преподавателя;
- `CRON_SECRET` — секрет запуска ежедневных напоминаний.

Переменные Google Sheets будут подключены на следующем этапе.

Код временно принимает и старую переменную `SUPABASE_SERVICE_ROLE_KEY`, чтобы
можно было заменить ключ без остановки бота. После успешного перехода старый
`service_role` следует отключить в Supabase.
