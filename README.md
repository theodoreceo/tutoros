# TutorOS

Минимальный бот сообщества VK для домашних работ в учебных мини-группах и на индивидуальных занятиях.

В репозитории остаются только:

- бот сообщества VK для преподавателя и учеников;
- группы, фактические уроки, домашние задания и результаты в Supabase;
- отдельная автоматически обновляемая статистика в Google Sheets;
- ежедневные напоминания о дедлайнах;
- SQL-схема и безопасная миграция старой базы.

Методическая карта не связана с ботом и может свободно меняться в течение года.

## Переменные окружения

Скопируйте `.env.example` в `.env.local` для локальной разработки. Никогда не
добавляйте `.env.local` в Git.

В Vercel Environment Variables хранятся:

- `SUPABASE_URL` — адрес проекта Supabase;
- `SUPABASE_SECRET_KEY` — серверный secret-ключ Supabase;
- `VK_GROUP_TOKEN` — ключ доступа сообщества VK;
- `VK_GROUP_ID` — числовой ID сообщества;
- `VK_CALLBACK_SECRET` — секрет проверки событий Callback API;
- `VK_CONFIRMATION_CODE` — строка, которую VK показывает при подтверждении сервера;
- `VK_API_VERSION` — версия VK API, по умолчанию `5.199`;
- `OWNER_VK_ID` — числовой VK ID преподавателя;
- `CRON_SECRET` — секрет запуска ежедневных напоминаний;
- `GOOGLE_SHEETS_WEBHOOK_SECRET` — секрет чтения статистики из TutorOS.

Код временно принимает старую переменную `SUPABASE_SERVICE_ROLE_KEY`, чтобы
ключ можно было заменить без остановки бота.

После развёртывания откройте `/api/vk-status`. Страница покажет адрес Callback API
и список отсутствующих настроек, но никогда не возвращает значения секретов.

## Первое подключение VK

1. Выполните в Supabase SQL Editor файл
   [`supabase/add_vk_channel.sql`](supabase/add_vk_channel.sql). Его можно безопасно
   выполнить повторно.
2. Добавьте перечисленные выше переменные VK в Vercel и запустите новое
   развёртывание.
3. Откройте `/api/vk-status` на домене Vercel и скопируйте `callback_url`.
4. В управлении сообществом VK добавьте этот адрес как Callback API-сервер,
   укажите тот же секрет, что в `VK_CALLBACK_SECRET`, и подтвердите сервер.
5. В событиях сервера включите «Входящее сообщение» и «Действие с кнопкой».
   После этого отправьте сообществу `/start` со своего аккаунта преподавателя.

## Рабочий контур

1. В сообщениях сообщества VK преподаватель создаёт мини-группу либо индивидуального ученика.
   Уровень обучения при необходимости указывается прямо в названии.
2. Для индивидуального ученика автоматически создаётся персональная группа из
   одного человека. Все ученики подключаются по персональной ссылке.
3. При создании ДЗ преподаватель вводит тему, выбирает быстрый дедлайн и тип
   работы, при необходимости прикладывает файл и вводит ответы или баллы одной
   строкой. Техническая запись урока создаётся только после подтверждения.
4. Ученик сдаёт ответы или файлы в VK. Автопроверка, ручная проверка и возврат
   на доработку сохраняются в Supabase.
5. Ошибочно созданное или больше не нужное ДЗ переносится в архив, а не
   удаляется. Его можно восстановить; уже сданные работы, файлы и оценки
   сохраняются.
6. Отдельный файл Google Sheets забирает из Supabase группы, учеников, ДЗ и
   результаты каждые 10 минут.

Годовой план, материалы и черновые изменения методики остаются в самостоятельной
Google-таблице и не могут изменить уже проведённые уроки или выданные ДЗ.

Подключение статистики описано в
[`google-apps-script/README.md`](google-apps-script/README.md), формат обмена —
в [`docs/sync-contract.md`](docs/sync-contract.md).

Миграция VK одновременно включает безопасный архив ДЗ. Старую миграцию архива
отдельно запускать не требуется.

Для уже работающей VK-базы после обновления выполните один раз
[`supabase/add_revision_workflow.sql`](supabase/add_revision_workflow.sql). Новая
установка через `add_vk_channel.sql` уже содержит ту же логику.
