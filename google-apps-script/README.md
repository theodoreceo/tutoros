# Подключение Google Sheets

Скрипт привязывается к рабочей таблице с листами:

- `Базовая`
- `Продвинутая`
- `Группа А`
- `Группа Б`

Он читает план группы из `B11:E`, находит точную тему по коду занятия в
методической карте и передаёт группы и занятия в TutorOS.

## Настройки скрипта

Добавьте в Apps Script → Project Settings → Script Properties:

- `TUTOROS_API_URL` — рабочий адрес Vercel без `/` в конце;
- `TUTOROS_SYNC_SECRET` — тот же случайный секрет, который записан в Vercel
  как `GOOGLE_SHEETS_WEBHOOK_SECRET`.

## Подключение

1. Вставьте `Code.gs` в проект Apps Script, привязанный к таблице.
2. Перезагрузите таблицу.
3. Один раз запустите `TutorOS → Подготовить таблицу`.
4. Запустите `TutorOS → Синхронизировать группы и уроки`.
5. Разверните скрипт как Web App: выполнение от вашего имени, доступ —
   `Anyone`. Секрет внутри каждого запроса не даёт постороннему записывать
   данные.
6. Скопируйте адрес Web App в переменную Vercel
   `GOOGLE_SHEETS_WEBHOOK_URL`.

Технические идентификаторы учеников записываются в скрытую строку 8. Все
события бота сохраняются на скрытом листе `_TutorOS`. Идентификатор группы
строится по внутреннему номеру листа, поэтому обычное переименование листа не
создаёт новую группу в базе.

Строка 3 заполняется автоматически:

- процент сданных ДЗ — по заданиям, которые были выданы этому ученику;
- процент посещений — по заполненным вручную отметкам в столбце
  `Был на занятии`;
- средний балл — по трём последним проверенным пробникам.

Для посещаемости распознаются `Да/Нет`, `Был/Не был`, `+/-`, `✅/❌`,
логические флажки и `1/0`. Пустые будущие занятия в расчёт не входят. После
ручного заполнения посещаемости нажмите `TutorOS → Обновить статистику`.

Чтобы добавить ещё одну мини-группу, скопируйте лист группы и добавьте одну
строку в массив `TUTOROS_GROUPS` в начале `Code.gs`.
