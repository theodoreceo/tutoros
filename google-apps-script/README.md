# Подключение Google Sheets

Для импорта методик скрипту нужны только листы:

- `Базовая`
- `Продвинутая`

Он читает строки методики из `A6:E` и передаёт шаблоны курса в TutorOS.
Конкретные группы, например `Базовая А1`, `Базовая А2` и `Продвинутая Б1`,
создаются непосредственно в Telegram-боте.

## Настройки скрипта

Добавьте в Apps Script → Project Settings → Script Properties:

- `TUTOROS_API_URL` — рабочий адрес Vercel без `/` в конце;
- `TUTOROS_SYNC_SECRET` — тот же случайный секрет, который записан в Vercel
  как `GOOGLE_SHEETS_WEBHOOK_SECRET`.

## Подключение

1. Вставьте `Code.gs` в проект Apps Script, привязанный к таблице.
2. Перезагрузите таблицу.
3. Один раз запустите `TutorOS → Подготовить таблицу`.
4. Запустите `TutorOS → Синхронизировать методики`.
5. Разверните скрипт как Web App: выполнение от вашего имени, доступ —
   `Anyone`. Секрет внутри каждого запроса не даёт постороннему записывать
   данные.
6. Скопируйте адрес Web App в переменную Vercel
   `GOOGLE_SHEETS_WEBHOOK_URL`.

Старые листы групп и журнал `_TutorOS` пока сохранены только для совместимости.
В новой архитектуре ученики, домашние задания и результаты принадлежат
Supabase. Отдельный автоматически обновляемый файл статистики подключается
следующим этапом.

Чтобы добавить ещё одну мини-группу, нажмите в Telegram
`➕ создать группу` и выберите базовую или продвинутую методику.
